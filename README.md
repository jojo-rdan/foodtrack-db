# FoodTrack DB

Proyecto de diseño, implementación y evolución de una base de datos relacional para un sistema de gestión de food trucks.

Desarrollado utilizando **SQL Server, DBeaver, Git y GitHub**.

El proyecto contempla cinco entidades principales:

- Foodtrucks
- Products
- Orders
- Order Items
- Locations

El objetivo es analizar los datos de origen, diseñar un modelo relacional, implementar sus tablas y restricciones, y documentar la evolución del esquema mediante control de versiones.

**Tecnologías:** SQL Server Express, DBeaver, SQL, Git y GitHub.
